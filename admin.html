Manage Ritumati

This website uses Google Sheets only for impact numbers. Photos and other website files stay directly in GitHub.

Daily workflow: change numbers in Google Sheets; upload/replace photos in GitHub.

Impact numbers

Open the Google Sheet and edit the Dashboard tab. Do not change the column names.

  • women_reached
  • sessions
  • districts_reached
  • satisfaction
  • annual_goal
  • annual_completed
Open Google Sheet

Photos

Put photos in the repository folders:

assets/photos/gallery/ for gallery images
assets/photos/testimonials/ for testimonial photos

To replace a starter image, keep the filename or update the matching image path in app.js.

GitHub update

  1. Open the Ritumati repository.
  2. Upload the new photo or edited file.
  3. Commit the change to main.
  4. GitHub Pages republishes the website automatically.
